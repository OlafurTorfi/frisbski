frisbski
========

Modernized to a Vue 3 SPA built with Vite.

Development
-----------

Requirements: Node.js 20+

```sh
npm install
npm run dev
```

Build
-----

```sh
npm run build
```

Production server
-----------------

Serves the built SPA from `dist/` (with history fallback).

```sh
npm run build
npm start
```
